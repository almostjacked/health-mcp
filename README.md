# health-mcp

Your health data (weight, body composition, calories, macros, water) as an MCP
data layer your AI can query — stored in YOUR OWN free Supabase project, synced
from Apple Health by an iOS Shortcut. Zero custody: nobody but you ever holds
your data or keys. Pair with [fitness-tools](https://github.com/almostjacked/fitness-tools)
for adaptive-TDEE math over this data.

Work in progress — install docs land with the first release.
